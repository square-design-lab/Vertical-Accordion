Where this goes

        
    
          
  1. Open Settings → Advanced → Code Injection and paste block 2 into the Footer box. Save.
    2. 
          
  2. Edit the page you want the accordion on and add a Code Block where it should sit.
    3. 
          
  3. Paste block 1 into the Code Block, delete anything else that's in there, and save.
    4. 
          
  4. Leave the editor and reload the live page — the accordion only builds on the published page.
    5. 
        

      

      

        
Good to know

        
    
          
  • A portfolio collection renders each item's full page sections. Everything else builds a card from the item fields.
    • 
          
  • Add ?featured to the collection URL to use starred items only.
    • 
          
  • Link straight to a panel with ?va-active=3.
    • 
          
  • More than one accordion on a page is fine — give each Code Block its own data-source and add a data-config attribute to override any setting per instance.
    • 
          
  • Scripting hooks: sdlVerticalAccordions:ready, :loaded, :open, :close. Each mount exposes el.sdlVerticalAccordion with open() / next() / prev() / refresh() / destroy().
